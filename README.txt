DILIMIZIN HAZINESI - GUNCEL SURUM

Dosyalar:
- index.html: Uygulamanin ana dosyasi
- manifest.webmanifest: Ana ekrana ekleme ayarlari
- sw.js: Cevrimdisi temel dosya onbellegi

GitHub Pages guncellemesi:
1. Bu ZIP dosyasini bilgisayarina indir ve klasore cikart.
2. GitHub deposuna gir: Code > Add file > Upload files.
3. Yeni index.html, manifest.webmanifest ve sw.js dosyalarini yukle. Mevcut dosyalari ayni adlarla degistir.
4. Commit changes ile kaydet. GitHub Pages birkac dakika icinde guncellenir.

TDK sozluk:
Uygulama, TDK'nin sozluk.gov.tr/gts arama servisinden kelime sonucunu uygulama icinde gostermeyi dener. Bu arayuz icin resmi gelistirici API garantisi bulunmadigindan servis/CORS erisimi zaman zaman calismayabilir. Boyle durumda ornek sozlukteki sinirli kelimeler gosterilir; kullanici TDK sayfasina yonlendirilmez.

Site adresi:
GitHub Pages adresi kullanici adini icerir. Kullanici adini gostermeyen ucretsiz bir adres icin Cloudflare Pages gibi farkli bir barindirma hizmetine tasinmasi gerekir.
